SSU Web API Tester

Lokale testpagina voor de read-only Web API van Simple Server Utilities.

Eerst éénmalig instellen

Omdat dit bestand rechtstreeks vanaf je pc opent, zet je voor deze test in de SSU-config: enableWebApi = true, webApiBindAddress = "127.0.0.1" en webApiAllowedOrigin = "null". Gebruik een token van minstens 16 tekens en herstart daarna de Minecraft-server.

Laat de bind address op 127.0.0.1 staan. De waarde null voor Allowed Origin is alleen bedoeld voor deze lokale testpagina die via file:// wordt geopend.
