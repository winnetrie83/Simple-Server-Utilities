- Core 2.0 lifecycle completion for storage, jobs, performance, transactions,

- Persistent server treasury and dashboard administration.
- Region rent/renew income distribution and treasury-funded cancellation refunds.
- Removal of src/test, JUnit dependencies and ModDevGradle unit-test setup.

Compatibility checks
--------------------
- Source version: 1.4.0-dev2.
- Network protocol: 16. Client and server must use the same build.
- Treasury account uses a deterministic UUID but is stored per world in the
  existing isolated economy folder.
- The treasury starts at zero and is excluded from player/account selectors.
- Existing account/transaction JSON remains readable.
- Existing rent-journal records omit treasury fields and therefore deserialize
  with zero/null defaults.
- Existing claim, region, snapshot v3, permission, home, warp, UI preference and
  aerial map-cache formats are unchanged.
