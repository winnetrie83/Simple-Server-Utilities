Full build limitation
---------------------
The Gradle build could not start in this container. Gradle 9.2.1 is not cached and the wrapper cannot
resolve services.gradle.org (`UnknownHostException`). The container provides Java 21 while the project
targets Java 25. A local Java 25 `gradlew.bat clean build` and real client/dedicated-server runtime test
remain required before dev3.3 can be considered build-confirmed or stable.
