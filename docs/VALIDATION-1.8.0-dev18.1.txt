Full build limitation in this container
---------------------------------------
The Gradle wrapper attempted to download Gradle 9.2.1, but the container has no DNS/network access to services.gradle.org. The container also provides Java 21 rather than the required Java 25. Therefore a complete NeoForge `gradlew.bat clean build` could not be executed here. The previous dev18.0 source was confirmed by the user to build; dev18.1 must still be built and tested with Java 25 by the user.
