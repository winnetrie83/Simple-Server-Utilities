# SSU 1.8.0-dev16.2 marker beam test

1. Build client and server from the exact same dev16.2 source.
2. Create markers in several colours on flat ground, hills, trees and near water.
3. Confirm each world beam is a visible beacon-like column rather than a thin line.
4. Confirm the beam starts at the top of the local world surface and never continues down to minimum build height.
5. Change terrain below a marker and wait at least two seconds; confirm the beam base follows the new surface.
6. Test at the configured maximum marker-beam distance and after changing dimension.
7. Confirm world-map/minimap marker icons and look-at labels remain unchanged.
