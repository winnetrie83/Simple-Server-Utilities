# SSU 1.6.0-dev1 validation status

## Completed static and isolated checks

- All JSON resources parse successfully.
- No merge markers or temporary patch tokens remain in the Java sources.
- Java parser-level checks found no malformed statements, unclosed source constructs or accidental patch fragments.
- The exact `UtilityMiningOutlineMath` source was compiled against minimal Minecraft geometry stubs and exercised with four shapes:
  - one block: 12 merged outer edges;
  - two adjacent blocks: 12 merged outer edges;
  - a flat 2x2 block rectangle: 12 merged outer edges;
  - an L shape: 18 merged outer edges;
  - no duplicate edges were produced.
- The exact `PlayerUiPreferences` source was compiled with minimal enum stubs and checked for schema-2 to schema-3 opt-in migration, brightness clamping and opaque RGB normalization.
- Dynamic exact log/ore permissions are recognized as boolean permissions by both the command warning layer and visual permission catalogue.

## Full build limitation in this environment

A complete `gradlew clean build` could not be executed in the packaging environment because the Gradle 9.2.1 distribution and NeoForge/Minecraft dependencies are not cached, outbound dependency download is unavailable, and the installed local JDK is Java 21 while SSU targets Java 25.

Build and gameplay validation therefore remain required on the normal SSU development computer with Java 25:

```bash
./gradlew clean build
```

Client and server must both use `1.6.0-dev1` because the network protocol is `23`.

1. Back up the test world and install the same build on client and server.
2. Confirm an existing player's mail, claims, regions, economy and settings still load.
3. Open Player Settings > Mining and enable Treecapitator and Veinminer.
4. Test both Sneak and Keybind activation, including releasing the key and changing dimensions.
5. Verify the outline is one merged external structure outline and that its two colors/brightness settings update.
6. Test permission limits at 1, 4 and a larger value; then grant each vanilla ore permission separately.
7. Add one custom tagged/modded log and ore, test their exact permissions, then test disabled-list precedence.
8. Test mining inside own, foreign and server-region protected areas.
9. Create text, link, TOP scoreboard and SELF scoreboard holograms and relog/restart to verify persistence.
10. Treat IMAGE holograms as definition/source placeholders in this build; the textured billboard renderer is not yet included.
