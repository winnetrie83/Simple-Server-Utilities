Implemented scope
-----------------
1. Added Entity Insight for nearby non-player living entities.
2. Green friendly / yellow neutral / red hostile overhead labels.
3. Neutral entities turn red while targeting a player and return to neutral when hostility ends.
4. Optional live current/max HP rendering; whole HP values omit .0 and fractional values use one decimal.
5. Personal enable, health, exact 0..32 block range and exact 1..50 nearest-entity cap.
6. Added default-granted permission key ssu.entity_insight.use.
7. Added Settings > Combat controls plus /ssu settings entity_insight fallback commands.
8. Server-authoritative nearest-entity selection and attitude state; client renders only the bounded server selection.
9. Players, invisible entities and SSU-managed NPCs are excluded to avoid identity-label conflicts/information leaks.
