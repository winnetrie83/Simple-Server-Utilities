Implemented scope
-----------------
1. In-world marker aim label
   - Camera/crosshair targeting selects only the closest marker within a bounded angular tolerance.
   - Looking at a marker disc draws one compact always-on-top billboard label.
   - Label contains the saved marker name and live player distance.
   - Label is tied to the existing in-world marker-icon toggle/range; marker beams remain independently controlled.

2. World Map cursor metadata
   - LOCATION panel and bottom status line show X/Y/Z, surface biome and surface block.
   - Metadata is captured with the terrain tile and remains available outside loaded client chunks.
   - Block/biome registry IDs are converted to compact readable names in the UI.

3. Aerial cache migration
   - Tile cache format increased from 4 to 5.
   - New cache root map-cache-v4 avoids interpreting old tiles as the new binary layout.
   - Surface block IDs and biome IDs are persisted per sampled map pixel.
