Implementation checks
---------------------
- Existing AerialMapStorage confirmed as asynchronous, server-isolated client disk persistence for explored tiles.
- Added validated personal live-update radius: 1..32 chunks, default 8.
- Radius is synchronized in both SsuMenuSnapshotPayload and recurring MinimapDataPayload.
- Loaded chunks are recaptured only inside the live radius.
- Cached off-radius terrain remains readable from disk without live recapture.
- Off-radius and inactive-dimension memory tiles expire after 200 client ticks without access.
- Actively viewed distant World Map tiles refresh their access time and are not evicted during use.
- Memory sweep runs every 40 client ticks.
- Hard transient per-dimension ceiling increased to 9216 tiles to avoid large-view LRU thrashing.
- Marker context frame now renders after child widgets as four non-overlapping gutters plus double outline.
- Relief weights and ground-light clamp strengthened; renderer fingerprint bumped so stale rendered pixels are not reused.
