SSU 1.9.0-dev3.33 validation notes
===================================

Scope
-----
Native Player NPC runtime foundation built on the user-confirmed working dev3.32 source.

Static/source checks completed
------------------------------
- Registered internal entity id: simpleserverutilities:player_npc.
- Native shell extends PathfinderMob and intentionally owns no vanilla goals.
- Player visual mode resolves to the native runtime while the persisted fallback entityType remains unchanged.
- Internal runtime entity is excluded from the normal Entity appearance picker.
- Dedicated entity renderer and model-layer registrations were added on the client mod bus.
- ClientMannequinSkinMixin was removed from source and mixin configuration.
- Live Java/resource source contains no remaining minecraft:mannequin / ClientMannequinSkinMixin dependency.
- Default Steve/Alex Wide/Slim state now uses an empty texture-sync entry; the packet codec/shape is unchanged.
- Network protocol remains 113 and NPC schema remains 14 because no payload or persistence shape changed.

Local build limitation in this workspace
----------------------------------------
A Gradle compile was attempted, but this execution environment has no outbound access to
services.gradle.org and no cached Gradle 9.2.1 distribution. The wrapper therefore stops
before Gradle/NeoForge compilation begins with an UnknownHostException. The container also
only exposes Java 21 while this project targets Java 25.

Because of that environment limitation, dev3.33 still needs the normal project build on the
user's Java 25/NeoForge 26.2 development machine. Runtime validation should follow
TESTING-1.9.0-dev3.33.md.
