# SSU 1.6.0-dev1 implementation notes

## Utility Mining

Treecapitator and Veinminer are opt-in per player. A feature only activates when all four gates pass: the global module config, the player's personal enabled setting, the selected activation input and effective permissions.

The client only sends activation state and the block under the crosshair. The server computes the complete selection, applies maximum-block permissions, validates log/ore eligibility and checks claims/regions. The break chain revalidates every selected block before using the player's normal game-mode block destruction path.

Treecapitator uses `minecraft:logs` plus configured custom logs, with a disabled list taking priority. It finds connected logs through all 26 neighbouring positions, then includes connected leaves within the configured Chebyshev range from the accepted logs. Leaves and logs share the same maximum-block budget.

Veinminer uses vanilla ore tags, `c:ores` and configured custom ores. Vanilla ore groups have independent permissions; custom/modded blocks receive exact dynamic block permissions.

## Holograms

Text, links and scoreboard definitions are persistent, dimension-aware and synchronized per player. Scoreboards support a global TOP list and a SELF view of the viewing player's score for a standard Minecraft scoreboard objective.

Image definitions already carry an internal resource identifier or validated HTTP(S) URL plus billboard width and height. Remote URLs are disabled by default. This build deliberately leaves image entries as source placeholders because Minecraft/NeoForge 26.2 moved custom textured world geometry into a dedicated extraction/submission pipeline; that renderer should be implemented and tested as an isolated follow-up instead of risking the stable text and mining feature set.

## Compatibility

- Mod version: `1.6.0-dev1`
- Network protocol: `23`
- Player UI preference schema: `3`
- Hologram store schema: `1`
- Existing server data stores are unchanged.

## Useful first-test commands

```text
/ssu utilitymining status
/ssu utilitymining tree leaf_range 3
/ssu utilitymining tree custom_logs add <namespace:block>
/ssu utilitymining vein custom_ores add <namespace:block>

/ssu hologram create text welcome Welcome to the server
/ssu hologram create link website "https://example.com" Open our website
/scoreboard objectives add kills minecraft.custom:minecraft.player_kills
/ssu hologram create scoreboard topkills kills top Top kills
/ssu hologram create scoreboard mykills kills self Your kills
```

Exact custom block permissions use normalized keys such as:

```text
ssu.treecapitator.block.examplemod.rubber_log
ssu.veinminer.block.examplemod.tin_ore
```
