SSU 1.9.0-dev3.25 static validation
====================================

Baseline: SSU 1.9.0-dev3.24.2
Scope: combined NPC Editor/Appearance + Behaviour/Patrol phase

Version/protocol/schema:
- mod_version = 1.9.0-dev3.25
- network protocol = 106
- NPC definition schema = 10
- NPC placement schema = 4
- NPC dialogue schema unchanged
- NPC Shop schema unchanged

Source changes:
- 794 Java source files total
- 16 changed/new Java files versus dev3.24.2
- 3 new NPC classes: NpcBehaviorMode, NpcPatrolMode, NpcPatrolPoint

Targeted invariants checked:
- New behavior modes: Native AI, Stationary, Look at players, Wander, Patrol
- Behavior values are present in NPC definition persistence and editor open/submit payloads
- Patrol mode/points are placement-specific and present in editor open/submit payloads
- Open payload record fields and every direct constructor call have matching arity
- Submit payload record fields and every direct constructor call have matching arity
- Local skin browser is backed by bounded recursive local PNG discovery
- Local skin paths are synchronously validated on NPC Save
- In-world patrol action is wired through NpcAdminActionPayload("patrol_route")
- Patrol block click adds/removes points; route finish is guarded by an actual HitResult.MISS
- Patrol editor sessions are cleared on logout/manager clear and dimension changes
- Schedule routing retains priority over ambient behavior
- Existing dev3.24.2 custom-name removal and skin rendering code remains present

Java checks:
- Self-contained new behavior/patrol classes compile with javac.
- Parse-oriented javac run across all 16 changed/new Java files found no high-signal Java syntax/type-shape diagnostics.
- The parse-oriented run still reports expected missing Minecraft/NeoForge packages because the project dependency classpath is unavailable in this container.

Full build limitation:
- A full Gradle/NeoForge compile cannot be completed in this container. The Gradle wrapper requires Gradle 9.2.1 and attempts to download it; outbound network access is unavailable here.
- Local Java 25 + NeoForge compilation/runtime testing remains required before treating dev3.25 as stable.

Not included in this phase:
- 3D live NPC editor preview (deferred until the current Minecraft 26.2 GUI/PIP API can be compiled/runtime-tested safely)
- Dialogue/Quest integration expansion (planned phase 2)
- Shop/Service/Templates expansion (planned phase 3)
