SSU 1.6.0-dev12 validation report
=================================

Scope
-----
Map UI redesign, personal markers, World Map/minimap/in-world marker rendering,
marker preferences, shared day/night map lighting, cached surface block-light,
sharper topographic relief and client aerial-cache format 4.

Environment limits
------------------
- Available Java runtime: OpenJDK 21.0.10.
- SSU requires Java 25.
- Gradle wrapper requests Gradle 9.2.1, which is not cached in this container.
- External wrapper download failed with UnknownHostException for services.gradle.org.
- Therefore a complete Gradle/NeoForge build was not claimed or performed here.
- Final build must be run locally with Java 25 using `gradlew.bat clean build`.
