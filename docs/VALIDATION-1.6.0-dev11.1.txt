SSU 1.6.0-dev11.1 validation report
===================================

Baseline
--------
- Parent source: SSU 1.6.0-dev11
- Mod version: 1.6.0-dev11.1
- Minecraft: 26.2
- NeoForge: 26.2.0.7-beta
- Java target: 25
- Network protocol: 33 (was 32)
- Player UI preference schema: 5 (was 4)
- All other storage schemas unchanged.

Implemented Block Information polish
------------------------------------
- Ordinary mode now renders only the translated block/entity name.
- A real Minecraft item icon appears only when a correct harvesting tool is
  required; the icon represents the minimum tagged tool tier (for example,
  diamond pickaxe for obsidian).
- The existing red/green vertical held-tool indicator remains.
- Registry ID, hardness, exact required-tool text and bounded blockstate
  properties moved to a separate personal debug mode.
- Entity registry IDs are shown in debug mode.
- New strict permission: ssu.block_information.debug, default false and resolved
  without operator bypass.
- Debug toggle is only offered in Settings when that permission is effective.
- Revoked permission disables technical details during the next periodic state
  synchronization without requiring a reconnect.

Validation
----------
- 282 Java files passed lexical string/comment and balanced delimiter scanning.
- BlockInformationStatePayload and BlockInformationClientState compiled with
  javac 21 against downgraded copies of the actual Minecraft 26.2 patched
  signatures plus minimal NeoForge signature stubs.
- SsuMenuSnapshotPayload compiled against the same Minecraft signatures,
  validating the expanded UI settings codec and record arity.
- PlayerUiPreferences schema-5 migration compiled dependency-free with its
  enum/source dependencies.
- PermissionKeys and PermissionCatalog compiled against Minecraft signatures.
- Focused assertions passed for version, protocol, schema, permission gate,
  compact rendering, real item rendering and entity-hit support.
- git diff --no-index --check reported no whitespace errors; exit 1 only means
  the baseline and dev11.1 trees intentionally differ.

Build limitation
----------------
A complete Gradle/NeoForge build could not run in this container because the
Gradle 9.2.1 distribution is not cached, external downloads are unavailable and
the installed runtime is Java 21 while SSU targets Java 25. Build locally with:

    gradlew.bat clean build
