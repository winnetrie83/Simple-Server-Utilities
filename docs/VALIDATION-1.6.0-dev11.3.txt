SSU 1.6.0-dev11.3 validation report
===================================

Baseline
--------
- Parent source: SSU 1.6.0-dev11.2
- Mod version: 1.6.0-dev11.3
- Minecraft: 26.2
- NeoForge: 26.2.0.7-beta
- Java target: 25
- Network protocol: 34 (unchanged)
- All persistent schemas unchanged.

Implemented Block Information recommendation polish
---------------------------------------------------
- Tool classification no longer stops when correct-tool-for-drops is false.
- Blocks in standard pickaxe/axe/shovel/hoe mining tags receive a compact
  recommended-tool icon when no hard harvesting requirement exists.
- Vanilla shears speed tags and cobweb receive a shears recommendation; sword
  efficient/instant tags receive a sword recommendation when shears do not win.
- Required tools retain their minimum tier; category recommendations use a
  lowest-tier icon to represent any tier.
- Required suitability uses Player.hasCorrectToolForDrops.
- Recommended suitability uses the held ItemStack destroy speed (> 1.0), so
  normal compatible modded tools can turn the indicator green as well.
- Debug output distinguishes Required and Recommended.

Validation
----------
- BlockInformationClientState compiled with javac 21 against major-version-
  downgraded copies of the actual Minecraft 26.2 patched signatures plus the
  existing minimal NeoForge/payload harness classes.
- Confirmed actual Minecraft 26.2 signatures expose ItemStack.getDestroySpeed,
  the four standard mineable tags, sword efficiency tags and shears speed tags.
- Java lexical string/comment and balanced delimiter scan passed for all Java
  source files.
- Focused source assertions passed for required/recommended modes, minimum-tier
  required icons, any-tier recommendations, special shears/sword selection,
  held-tool efficiency and unchanged network protocol 34.
- diff --check reported no whitespace errors.

Build limitation
----------------
A complete Gradle/NeoForge build could not run in this container because the
Gradle 9.2.1 distribution is not cached, external downloads are unavailable and
the installed runtime is Java 21 while SSU targets Java 25. Build locally with:

    gradlew.bat clean build
