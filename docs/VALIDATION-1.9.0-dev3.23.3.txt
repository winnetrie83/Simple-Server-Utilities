Build limitation
----------------
A real Gradle/NeoForge compile could not be run in this environment. The wrapper attempts to download
Gradle 9.2.1 from services.gradle.org, but the container has no external network access. The container
also has Java 21 while this project targets Java 25. Run locally with Java 25:

    gradlew.bat clean build

or at minimum:

    gradlew.bat compileJava

Then execute docs/TESTING-1.9.0-dev3.23.3.2.md in a Minecraft 26.2 client/server test.
