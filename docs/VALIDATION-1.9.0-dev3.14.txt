Todo implementation summary:
- Mines require complete containment by an SSU Region and persist an auto-derived containing Region.
- Newly created automatic Mine permission keys use ssu.mines.use.<mine-id>; existing non-empty/custom keys are preserved.
- Jail Parent is no longer manually chosen; it is derived from Jail bounds.
- Jail Cell radius was removed from definition/GUI/runtime confinement.
- Jail and Task Area use a dedicated admin-only 3D border layer.
- Jail cells can be selected, individually moved and individually deleted with active-assignment safety.
- Jail punishment time fields display explicit units.
- Mine/Jail Setup Tools are exposed via Admin Tools and redundant in-editor Setup Tool buttons are removed.
- Nested Jail task mining in a Mine requires both global and Mine-specific permissions through a jail-safe resolver; all unrelated jailed permissions remain blocked.
- Mine generated status holograms can be explicitly removed.
- Jail Administration contains an active-prisoner overview with filters, progress/status details and quick admin actions.
