Implemented scope
- Removed the temporary held-item/offhand blacklist workflow completely.
- Added a visible administrator inventory picker with the 9x3 main inventory and 9-slot hotbar.
- The server receives only the selected inventory slot and revalidates its current item before blacklisting.
- Added manual full registry-ID entry with client-side visual preview and server-authoritative registry validation.
- Invalid, missing and empty/air item IDs are rejected and never persisted.
- Blacklist rows visibly show the registered item icon, display name and canonical registry ID.
- Administrator cancellation and seizure now require a non-empty reason of at most 200 characters.
- Cancellation/seizure reasons are included in seller mail and server logs.
- A seizure reason is stored durably on the listing so recovery after restart preserves the same reason.
