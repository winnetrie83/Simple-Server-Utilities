SSU 1.3.0-dev3.4 validation report
===================================

Base source
-----------
SSU-1.3.0-dev3.3.1-source.zip

Version and compatibility
-------------------------
- Mod version: 1.3.0-dev3.4
- Network protocol: 11 (unchanged)
- Save/storage schemas: unchanged
- Server-authoritative claim and region data: unchanged

Implemented checks
------------------
- Shared map detail is one composite pixel per world block.
- Claim map uses separate published and building textures.
- Previous claim terrain is remapped by world bounds while a new view builds.
- Claim and world map viewports update locally before the server round-trip.
- Stale centre/radius responses are ignored.
- Right-mouse dragging offsets terrain and overlays live.
- Floating drag message was removed; fixed instructions remain.
- World-map terrain uses the same target viewport as claim/region overlays.
- Leaf-tagged blocks use an opaque aerial-canopy path.
- Local normalized hill shading and broad relief shading are both active.
- Water biome colour and depth path from dev3.3.1 remains present.

Static validation
-----------------
- 148 Java source files passed delimiter and lexical-balance checks.
- javac parse scan found no Java syntax errors. Dependency-resolution errors are expected because Minecraft/NeoForge libraries are not installed in this sandbox.
- 14 JSON files parsed successfully.
- 13 PNG files passed signature, chunk and CRC validation.
- Source consistency assertions passed for version, one-pixel constants, leaf handling, relief passes, double buffering and local viewport updates.
- Source ZIP integrity test passed.

Build limitation
----------------
A full Gradle build was attempted but could not start because the sandbox cannot resolve services.gradle.org to download Gradle 9.2.1. The sandbox also provides Java 21.0.10, while this project requires Java 25. This source version is therefore statically validated but not compiled or run in Minecraft here.
