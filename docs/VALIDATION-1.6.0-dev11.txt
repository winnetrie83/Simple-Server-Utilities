SSU 1.6.0-dev11 validation report
=================================

Baseline
--------
- Parent source: SSU 1.6.0-dev10.2
- Mod version: 1.6.0-dev11
- Minecraft: 26.2
- NeoForge: 26.2.0.7-beta
- Java target: 25
- Network protocol: 32 (was 31)
- Player UI preference schema: 4 (was 3)
- Custom statistic definition/value schema: 1 (new, isolated)
- Region record schema: 4 (unchanged)
- Hologram schema: 4 (unchanged)
- Mailbox schema: 3 (unchanged)
- Border player-preference schema: 2 (unchanged)

Implemented todo points
-----------------------
16. Block Information module
- Server module switch and strict permission capability gate.
- Persistent personal player toggle.
- Local client block inspection with no per-look server packet.
- Name, registry ID, namespace/mod label, hardness, tool state and bounded
  sorted state properties.

17-19. Custom Player Statistics, management, storage and performance
- Definition types: block broken/placed, entity killed, player death,
  damage dealt/taken and online play time.
- Optional exact registry target or wildcard where the event supports it.
- Searchable paged administrator screen and dedicated create/edit form.
- Pause/resume, all-player reset and double-confirmed deletion.
- Server-authoritative validation and permission checks.
- Event-type and exact/wildcard indexes; an event does not scan all definitions.
- Damage stored as hundredths; additions saturate at Long.MAX_VALUE.
- Isolated definition plus per-player JSON records through the existing
  dirty-record/single-writer storage service.
- Five-second dirty-player batching plus logout, module-stop, reload and
  shutdown saves.
- Broken files are archived; definition count and leaderboard sizes are bounded.

20. Floating Text integration
- {{stat:<id>}} resolves the current viewer's formatted value.
- {{rank:<id>}} resolves the current viewer's rank or '-'.
- SCOREBOARD objective ssu:<id> supports SELF and TOP modes.
- Existing maximum row and independent per-hologram refresh scheduling apply.
- Missing/disabled statistics produce bounded safe fallback text.

Build limitation
----------------
A complete Gradle/NeoForge build could not run in this container. The Gradle
wrapper requires an uncached Gradle 9.2.1 distribution and external downloads
are unavailable; the installed runtime is Java 21 while SSU targets Java 25.
The targeted signature compilations above reduce API risk but do not replace the
required local build and Minecraft test. Build locally with Java 25:

    gradlew.bat clean build
