ISSUES FOUND AND CORRECTED DURING VALIDATION
- The onboarding Rules screen originally allowed the confirmation-stage identifier to fall through the generic Rules branch. The screen was rewritten so Rules acceptance always requires two separate server-authoritative steps.
- Long Rules/introduction documents received explicit page controls so rich text remains readable in the compact screen.
- Player resolution in onboarding administration was changed away from the uncertain profile-cache API and now uses online lookup plus the persistent moderation identity store.
- Warning duration now initializes from the server-provided moderation default instead of a hard-coded client value.
- Kit claims and jail buyouts now use dedicated economy transaction categories rather than unrelated generic categories.
