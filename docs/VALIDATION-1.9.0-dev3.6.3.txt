It could not start because Gradle 9.2.1 is not cached locally and the wrapper attempted to reach services.gradle.org, which is unavailable in this container. The container also provides Java 21 while this project requests the Java 25 toolchain. Run the final build locally with Java 25:

    gradlew.bat clean build
