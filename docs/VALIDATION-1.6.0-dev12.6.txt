Implemented scope
-----------------
1. Stable apparent marker size
   - The filled camera-facing marker disc scales proportionally with distance after a 16-block reference distance.
   - Scaling is clamped to the existing 512-block in-world marker range.
   - Near markers retain the previous compact world size.

2. Stable readable aimed label
   - Text scale, background dimensions and camera-relative vertical offset use the same bounded visual scale.
   - The label therefore retains approximately constant screen size alongside the marker disc.

3. Long-range aim selection
   - Replaced the former capped world-space tolerance with a fixed angular tolerance.
   - This keeps crosshair selection aligned with the compensated marker size at long distance.
