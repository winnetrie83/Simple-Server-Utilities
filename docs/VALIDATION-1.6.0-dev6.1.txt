Validated changes
- Plain visible editor text is separated from per-character rich-style state.
- Legacy formatting is decoded only at load and encoded only at save.
- Selection color and B/I/U/S changes mutate the rich-style model without inserting visible control codes.
- Non-empty selection is retained while toolbar/palette controls receive focus.
- Client-only MultiLineEditBox content injection renders styled Components for immediate editor preview.
- World hologram renderer parses rich segments and does not submit raw formatting codes to TextGizmo.
- Styled hitbox width follows the same parsed segments as world rendering.
- Tree discovery reconnects across one missing vertical log and accepts canopy-backed small remnants.
- Same-family log/wood/stripped/stem/hyphae variants normalize together; species and namespaces remain separate.
- Conventionally named modded wood variants have a fallback when their logs tag is incomplete.
